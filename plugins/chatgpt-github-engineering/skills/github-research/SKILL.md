# GitHub Research

Restate the research question, repository scope, and decision it will inform.
Search the connected GitHub repository by distinctive symbols, filenames,
errors, and concepts. Prefer primary repository sources: current code,
configuration, tests, ADRs, issues, pull requests, and release notes.

When external facts are required and web research is available, use original
documentation, standards, or papers rather than secondary summaries. Clearly
separate repository findings from external findings and inference.

For every material conclusion provide a direct repository locator or external
source link. Report negative searches as bounded observations, not proof of
absence. Note inaccessible repositories, branches, large files, or unavailable
history as evidence limits.

Return a concise research memo with question, findings, evidence, uncertainties,
and recommended next action. Do not edit the repository or claim that the memo
was saved there.
